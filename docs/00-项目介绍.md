# 项目介绍

LifeOS AI 是一个个人操作系统方向的 AI 项目，目标是把用户每天产生的想法、经历、情绪、学习、工作和创作素材转化为长期可用的记忆系统。

本项目的第一个落地点是“视频日记智能体”。用户可以用视频或语音自然记录一天的经历，系统负责理解内容、提炼事件、识别情绪、提出反思问题，并把重要信息写入个人知识库。

## 为什么从视频日记开始

视频日记有三个优势：

- 低摩擦：用户只需要说出来，不需要先组织成文章。
- 信息密度高：语气、停顿、情绪、场景都可能包含价值。
- 复利明显：长期积累后，可以形成个人记忆、成长轨迹和内容素材库。

## 目标用户

- 希望长期记录成长和复盘的人
- 创业者、产品经理、创作者、咨询顾问
- 想建立第二大脑和个人知识库的人
- 希望把日常思考转化为文章、短视频、播客素材的人

## 产品形态

早期产品可以是半自动工作流：

- 用户上传视频或语音
- 系统转写并运行 Agent 分析
- 输出结构化日记、复盘问题、记忆卡片和内容草稿
- 自动写入飞书知识库

后续可以演进为独立 Web App、移动端 App、桌面端助手或飞书插件。
