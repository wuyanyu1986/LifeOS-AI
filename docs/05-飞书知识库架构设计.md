# 飞书知识库架构设计

飞书知识库是 LifeOS AI 早期最适合的落地载体。它可以承载文档、表格、知识库目录和协作流程。

## 知识库结构

```text
LifeOS AI
├── 00 Inbox
├── 01 Daily Journal
├── 02 Memory Cards
├── 03 Projects
├── 04 People
├── 05 Goals
├── 06 Content Studio
└── 99 System
```

## 00 Inbox

保存未经整理的输入：

- 原始转写文本
- 上传文件链接
- 临时想法
- 待处理材料

## 01 Daily Journal

每篇日记一份文档，建议标题格式：

```text
YYYY-MM-DD - 日记标题
```

文档模板：

```text
# 标题

## 原始信息

## 今日摘要

## 关键事件

## 情绪轨迹

## 认知挑战

## 行动项

## 记忆候选

## 内容候选
```

## 02 Memory Cards

用于存储长期记忆。每条记忆应包含：

- 类型
- 内容
- 来源日期
- 来源日记
- 置信度
- 是否已确认

## 03 Projects

按项目沉淀相关日记、决策、任务和复盘。

## 04 People

记录与人物相关的事实、关系、偏好和互动历史。

## 05 Goals

记录长期目标、阶段目标、习惯和进展。

## 06 Content Studio

保存从日记生成的内容资产：

- 文章草稿
- 短视频脚本
- 播客提纲
- 社交媒体素材

## 99 System

保存模板、Prompt、字段说明、自动化配置和版本记录。

## 每日日记审核结构

```text
每日成长
└── YYYY-MM-DD                    # 标准解析稿，先审核
    ├── YYYY-MM-DD 视频脚本和视频文案  # 独立提醒、独立审核
    └── YYYY-MM-DD 公众号文章          # 独立提醒、独立审核
```

审核状态保存在本地状态注册表中，飞书文档链接作为审核入口。标准解析稿审核通过前，不创建两个衍生文档。
