# 用户旅程与核心流程

## 用户旅程

### 1. 记录

用户在一天结束后打开录制工具，说出今天发生的事、自己的感受、遇到的问题和下一步想法。

### 2. 导入

用户上传视频、音频或粘贴转写文本。系统创建一条新的日记记录。

### 3. 理解

日记理解 Agent 读取转写文本，提炼核心事件、情绪和主题。

### 4. 反思

认知挑战 Agent 基于日记内容提出问题，帮助用户看到盲区和可行动方向。

### 5. 归档

个人记忆 Agent 提取长期价值信息，写入对应的飞书知识库结构。

### 6. 审核标准解析稿

系统在飞书知识库检测到新的日期文档后发送提醒。用户审核事实、结构和隐私内容；审核通过前不生成视频脚本和公众号文章。

### 7. 复用

内容生成 Agent 产出文章、脚本、复盘卡片或行动计划。

### 8. 审核衍生内容

视频脚本和公众号文章分别发送消息提醒、分别审核。任一内容退回时，只修改对应分支。

## 核心流程

```text
Input
  -> Transcription
  -> Standard Parsed Note
  -> Feishu Archive
  -> Parsed Note Review
  -> Video Script + Independent Review
  -> WeChat Article + Independent Review
  -> Completed
```

## 日记处理状态

- `created`：已创建，等待输入。
- `transcribed`：已完成转写。
- `parsed_pending_review`：标准解析稿已进入飞书，等待审核。
- `parsed_changes_requested`：标准解析稿被退回修改。
- `generating_derivatives`：标准解析稿已通过，正在生成衍生内容。
- `derivatives_pending_review`：视频脚本或公众号文章等待独立审核。
- `completed`：视频脚本和公众号文章均审核通过。
- `failed`：流程失败，等待重试或人工处理。

## 异常流程

- 转写质量低：提示用户补充关键词或重新上传。
- 内容过短：只生成摘要和追问，不写入长期记忆。
- 涉及敏感内容：默认标记为私密，不进入公开内容生成。
- Agent 输出冲突：保留多个判断，等待用户确认。
