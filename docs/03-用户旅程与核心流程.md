# 用户旅程与核心流程

## 用户旅程

### 1. 记录

用户在一天结束后打开录制工具，说出今天发生的事、自己的感受、遇到的问题和下一步想法。

### 2. 导入

用户上传视频、音频或粘贴转写文本。系统创建一条新的日记记录。

### 3. 理解

日记理解 Agent 读取转写文本，提炼核心事件、情绪和主题。

### 4. 反思

认知挑战 Agent 基于日记内容提出问题，帮助用户看到盲区和可行动方向。

### 5. 归档

个人记忆 Agent 提取长期价值信息，写入对应的飞书知识库结构。

### 6. 复用

内容生成 Agent 产出文章、脚本、复盘卡片或行动计划。

## 核心流程

```text
Input
  -> Transcription
  -> Diary Analysis
  -> Cognitive Challenge
  -> Memory Extraction
  -> Content Generation
  -> Feishu Archive
```

## 日记处理状态

- `created`：已创建，等待输入。
- `transcribed`：已完成转写。
- `analyzed`：已完成日记理解。
- `challenged`：已完成认知挑战。
- `memorized`：已完成记忆提取。
- `published`：已生成内容草稿。
- `archived`：已写入知识库。

## 异常流程

- 转写质量低：提示用户补充关键词或重新上传。
- 内容过短：只生成摘要和追问，不写入长期记忆。
- 涉及敏感内容：默认标记为私密，不进入公开内容生成。
- Agent 输出冲突：保留多个判断，等待用户确认。
