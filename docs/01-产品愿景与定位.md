# 产品愿景与定位

## 愿景

LifeOS AI 希望成为用户的个人成长操作系统。它不只是记录信息，而是帮助用户理解自己、管理记忆、形成行动，并把真实经历转化为可复用的知识和内容资产。

## 定位

第一阶段定位为：

> 面向个人复盘和内容沉淀的视频日记 AI 助手。

它不是普通日记软件，也不是单纯的语音转文字工具，而是一个围绕“个人记忆”和“认知成长”设计的 Agent 工作流。

## 核心差异

- 从自然表达开始，而不是从表单开始。
- 不只总结内容，还会追问认知盲区和行动承诺。
- 记忆结构面向长期积累，而不是一次性聊天记录。
- 输出既服务自我复盘，也服务内容创作。

## 产品原则

- 用户拥有原始记录和结构化结果。
- 系统应尽量减少记录负担。
- AI 输出必须可追溯到原始日记。
- 先做高质量个人工作流，再考虑规模化社交功能。
- 默认保护隐私，谨慎处理敏感记忆。

## 成功标准

早期成功不以用户数衡量，而以复用频率和记忆质量衡量：

- 用户是否愿意每周记录三次以上。
- 用户是否能从历史日记中找回重要线索。
- Agent 是否能提出有价值的反思问题。
- 输出是否能转化为文章、计划、任务或决策。
