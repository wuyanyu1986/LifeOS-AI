# PRD V1.0

## 背景

用户每天会产生大量想法和经历，但大部分没有被记录、整理和复用。传统日记依赖手写或打字，门槛较高；普通 AI 聊天记录又缺乏长期记忆结构。

LifeOS AI V1.0 要解决的问题是：让用户通过视频或语音快速记录，并自动生成可复盘、可检索、可沉淀的结构化日记。

## 目标

- 支持一次视频日记从输入到归档的完整流程。
- 生成结构化日记摘要、事件、情绪、洞察、行动项。
- 给出认知挑战问题，帮助用户反思。
- 将长期价值信息写入个人记忆库。
- 生成可发布或可继续编辑的内容草稿。

## 非目标

- 不在 V1.0 实现完整移动端 App。
- 不在 V1.0 做复杂社交网络。
- 不在 V1.0 做自动心理诊断或医疗建议。
- 不在 V1.0 追求全自动替用户做重大决策。

## 用户故事

### 记录者

作为用户，我希望上传一段视频日记后，系统自动转写并总结，这样我不需要手动整理一天的经历。

### 复盘者

作为用户，我希望系统指出我的反复模式、情绪变化和可能的认知偏差，这样我可以更清楚地理解自己。

### 创作者

作为用户，我希望系统从日记中提取可以公开表达的素材，这样我可以生成文章、短视频脚本或播客提纲。

## 功能需求

### F1 视频或语音输入

- 支持本地上传视频、音频或转写文本。
- 保存原始文件引用和导入时间。
- 支持手动补充标题、日期和标签。

### F2 转写与清洗

- 将语音转为文本。
- 去除明显口癖和重复片段。
- 保留关键原话用于引用和追溯。

### F3 日记理解

- 输出今日主题、关键事件、人物、地点、情绪、冲突和收获。
- 区分事实、感受、判断和行动。
- 给出 3 到 5 条核心摘要。

### F4 认知挑战

- 识别可能的过度概括、灾难化、逃避、合理化等模式。
- 以问题形式提出挑战，不用指责式语气。
- 给出可执行的下一步建议。

### F5 个人记忆沉淀

- 提取长期有价值的信息。
- 分类到人物、项目、目标、偏好、经验、决策等记忆类型。
- 标注置信度和来源。

### F6 内容生成

- 从日记中生成文章提纲、朋友圈草稿、短视频脚本或播客提纲。
- 区分私密内容和可公开内容。
- 保留用户个人表达风格。

### F7 飞书知识库归档

- 将结构化结果写入飞书文档或知识库。
- 每篇日记有固定模板。
- 支持按日期、主题、项目和人物检索。

## 数据结构草案

```json
{
  "entry_id": "2026-08-24-001",
  "date": "2026-08-24",
  "title": "一次视频日记",
  "source_type": "video",
  "summary": [],
  "events": [],
  "emotions": [],
  "insights": [],
  "action_items": [],
  "memory_candidates": [],
  "content_candidates": []
}
```

## 验收标准

- 输入一段 3 到 10 分钟的视频日记，可以产出完整结构化 Markdown。
- 输出包含摘要、事件、情绪、认知挑战、行动项和记忆卡片。
- 结果可以手动复制或自动写入飞书知识库。
- 每条长期记忆都能追溯到原始日记日期和片段。
